# Contributing

Keep contributions clean-room and privacy-first. Do not submit code, assets, strings, screenshots, binaries, or design details copied from proprietary screen translator products, and do not add DRM or screenshot-protection bypasses.

Before a PR, run `npm run build`, `npm test`, and `npm run typecheck`. New capture or translation providers must state data flows, permissions, license, and whether any content can leave the device. Cloud providers must be opt-in and off by default.
